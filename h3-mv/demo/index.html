H3 MV

完成した曲をミュージックビデオにする

完成音源、歌詞、キャラクター画像から、元曲と字幕を合わせたMVを作るComfyUIワークフロー。
Create a music video from a finished song, exact lyrics and a character sheet. The final export restores the original audio and can add timed subtitles.

専用ZIPを取得 / DownloadGitHubのREADMEnoteの解説記事

H3_MV_20261105183000_v1.2.1.zip

用意するもの / What to bring

完成音源 / Finished song

YuE2などで用意した元曲を音源バンドルにします。
Prepare a bundle from the original song, for example a track made in YuE2.

歌詞 / Exact lyrics

歌詞をバンドルに含め、必要に応じてWhisperで字幕の時刻を合わせます。
Include exact lyrics in the bundle and use Whisper to time subtitles if needed.

キャラクター画像 / Character sheet

シートと演出指示で、画面に出す人物や歌唱者を指定します。
Use the sheet and directions to identify the characters and performers.

導入 / Setup

  1. 専用ZIPを展開し、python -B verify_package.pyを実行します。
    Extract the named ZIP and run the package verifier.
  2. 同梱の6フォルダーをComfyUIのcustom_nodes/へ置き、ComfyUIのPythonへrequirements.txtの依存ライブラリを入れます。
    Copy the 6 node folders into ComfyUI and install the requirements with its Python.
  3. 指定のH3モデル4本、CUDAに対応するPyTorch・Triton、FFmpeg／ffprobe、LM Studioを準備します。字幕の時刻合わせにはWhisperを指定します。
    Set up the four H3 model files, CUDA PyTorch and Triton, FFmpeg and LM Studio. Configure Whisper for subtitle alignment.
  4. ComfyUIを再起動し、ZIPのworkflows/からMV用JSONを開きます。
    Restart ComfyUI and open the MV workflow from the ZIP.

モデルの配置先と環境設定 / Model paths and detailed setup

まず20秒で確認 / First run: 20 seconds

音源バンドルとキャラクター画像を選び、演出を入力します。20秒、フェード1秒で試し、口の動き・人物・元曲・字幕を確認してから「音源末尾まで（可変尺）」へ切り替えます。
Select the bundle and character sheet, enter directions, and try 20 seconds with a one-second fade. Check the performers, lip movement, original song and subtitles before switching to the full song.

最終ノードで元曲を合わせ、設定に応じて字幕やフェードを合成します。完成ファイルはComfyUI/output/video/MV/<title_timestamp>/final.mp4です。
The final node restores the original song and applies configured subtitles and fades. The output is the final.mp4 shown above.
