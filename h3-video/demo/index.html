導入 / Setup

  1. 専用ZIPを展開し、python -B verify_package.pyを実行します。
    Extract the named ZIP and run the package verifier.
  2. 同梱の5フォルダーをComfyUIのcustom_nodes/へ置き、ComfyUIのPythonへrequirements.txtの依存ライブラリを入れます。
    Copy the 5 node folders into ComfyUI and install the requirements with its Python.
  3. 指定のH3モデル4本、CUDAに対応するPyTorch・Triton、FFmpeg／ffprobe、LM Studioを準備します。音声検査を使う場合はWhisperも設定します。
    Set up the four H3 model files, CUDA PyTorch and Triton, FFmpeg and LM Studio. Configure Whisper for speech review.
  4. ComfyUIを再起動し、ZIPのworkflows/から使いたい方式のJSONを開きます。
    Restart ComfyUI and open the workflow you want from the ZIP.

モデルの配置先と環境設定 / Model paths and detailed setup

最初は5秒で試す / First run: 5 seconds

画像を使う方式は該当の画像欄を埋めます。「動画指示」と尺の設定を5秒に揃えて実行し、プレビューで画と音を確認します。文章内に明示した尺が優先されます。
Fill the image inputs when required. Set a five-second duration in both the instructions and the duration control, queue the run, then check the picture and audio. An explicit duration in the instructions takes precedence.

完成MP4はComfyUI/output/video/MiniMax_H3/H3_T2V-I2V-Ref2V/に保存されます。長い生成を再開する場合は入力とキャッシュ名を揃えます。
Find the completed MP4 in the output folder above. Keep the same inputs and cache name to resume a longer run.
