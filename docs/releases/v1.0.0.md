# ComfyUI H3 Workflows v1.0.0

Initial standalone source distribution: T2V, I2V and Ref2V workflows with an original prompt helper. Four-step video, two-step audio refinement, variable duration and optional LM Studio conversion are preserved.

自作プロンプト補助ノードとT2V・I2V・Ref2Vの独立配布版です。映像4ステップ、音声再精錬2ステップ、可変尺、LM Studio変換の構成を保持しています。

Models are linked, not bundled. Obtain four pinned external node projects and apply the included compatibility patches following the bilingual README. Their separate licenses remain applicable.

モデルはリンク案内のみです。外部4ノードはREADMEに従い固定版を取得して互換パッチを適用します。各依存のライセンスは維持されます。

Offline reconstruction and package checks are documented in VALIDATION.md. This restructuring was not tested with a fresh GPU generation; historical results and unverified conditions are explicitly separated.

復元・配布物検査の範囲はVALIDATION.mdを参照してください。再構成後のGPU生成は未実施で、元記録の結果と区別しています。
