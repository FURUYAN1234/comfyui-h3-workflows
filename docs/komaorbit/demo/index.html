COMFYUI WORKFLOW · LOCAL GENERATION

KomaOrbit

一枚絵を読み込み、人物と背景を3Dの構図として探索する。回転・平行移動・拡大縮小をマウスで操作し、元画像と同じ幅・高さで保存します。

Explore a composition around an illustrated subject. Orbit, pan and zoom locally in ComfyUI, then export a PNG at the source image dimensions.

This is a setup and usage guide. Run the workflow in local ComfyUI with your own input and separately obtained models.

3D構図ビューアーの操作 / Camera controls

生成後は、下側の「回転・構図・保存」グループにある「固定3D • 左ドラッグ回転／右ドラッグパン／ホイール拡大縮小」という画像表示を使います。画像の中にマウスを置いて操作してください。
After generation, find the 3D image viewer titled “固定3D • 左ドラッグ回転／右ドラッグパン／ホイール拡大縮小” in the lower Explore and save group. Place the pointer inside its image.

保存する画角を調整

「中央に戻す」で初期構図へ。「この視点を保存」で白枠内を元画像の寸法でPNGにします。角度別画像が必要なときは、同じグループの「固定3D • 背景付き・低／水平／高の全視点」にある「全視点をフォルダー保存」を使います。こちらは処理解像度で、高さ3段階×73方位を書き出します。
Reset with “中央に戻す” and save the framed view with “この視点を保存”. Use the separate angle-image viewer and its folder-export button for 3 heights × 73 directions at processing resolution.

導入の流れ / Setup

  1. Releaseの名前付きZIPを展開し、verify_package.pyで確認。
    Extract the named release ZIP and verify its files.
  2. ComfyUI用Pythonでinstall.py --comfy /path/to/ComfyUI --dependenciesを実行。
    Install the three node packages and their dependencies using ComfyUI's Python.
  3. READMEに従ってWorldMirrorの公式コード、CUDA描画環境、指定モデルを準備。
    Prepare the separately licensed WorldMirror source, CUDA renderer and listed models.
  4. ComfyUIを再起動し、KomaOrbit.jsonを開き、上側の「一枚絵を読み込む / Import」で自分の画像を指定。「作成方法」が「固定3Dを新規生成」であることを確認し、「実行する」を押します。
    Restart ComfyUI, open the workflow and select your image in “一枚絵を読み込む / Import”. Keep the new fixed-3D generation mode and run.

Linux / WSL2とNVIDIA CUDAを対象に検証しています。対応版・手順・モデルURLはREADME、検証範囲はVALIDATIONを参照。
See the README for versions, model URLs and installation, and VALIDATION for the actual test scope.

出力と制約 / Outputs and limits

元画像と同じ寸法のPNG、角度別画像、Gaussian Splat形式のPLYを保存できます。PLYの読み込みには対応するアプリが必要です。通常のボーン付きメッシュではありません。見えない形状・背景は推定され、顔や背面の厳密な一致は保証されません。
Export source-size PNGs, a view grid and Gaussian-splat PLY. Use a compatible splat importer. Hidden geometry and background are inferred; exact identity from every angle is not guaranteed.
