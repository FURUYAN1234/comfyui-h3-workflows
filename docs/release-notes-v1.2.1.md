# v1.2.1 — Multi-character MV sheets / 複数キャラシート対応MV

This release extends the existing YuE2-connected MV workflow to keep 1–12 registered people in one character sheet distinct. YuE2 v1.6.1 exports schema-v2 character metadata; the MV input maps each person to a separate `<Subject N>` and stable `(SN)` speaker ID while using the same `<Picture 1>` sheet. / 既存のYuE2連携MVを、1枚のキャラクターシートに登録された1～12人を別々に保持できるよう拡張しました。YuE2 v1.6.1がschema v2人物情報を書き出し、MV入力が同じ `<Picture 1>` の各人物を別々の `<Subject N>` と安定 `(SN)` 話者IDへ対応付けます。

Repeated poses and expressions remain views of the same person. Merging, splitting, identity swaps, and unregistered clones are prohibited. For solo lyric cues, exactly one visible subject lip-syncs; the workflow does not infer a voice owner from timbre alone. / 表情・ポーズ差分は同一人物の別ビューとして扱います。人物の融合・分裂・入れ替わり・未登録の分身を禁止し、ソロ歌詞は見える1人だけが口を動かします。声質だけから人物への声の割当は推測しません。

Whisper-aligned lyric text stays in the final subtitle renderer. For an unassigned multi-character vocal, H3 receives only the authoritative source audio and vocal-activity windows, so exact subtitles can be burned without inventing a singer identity or duplicating the lyric as generated dialogue. Sixty-second timelines use an explicit `01:00.000` endpoint to prevent seconds from being interpreted as minutes. / Whisperで整列した歌詞本文は最終字幕だけに使用します。歌唱者未指定の複数人物MVでは、H3へ元音源と歌唱区間だけを渡すため、歌唱者の捏造や生成台詞としての二重歌唱を避けながら正確な字幕を焼き込めます。60秒のタイムラインは終端を `01:00.000` と明示し、秒を分として誤解する変換を防ぎます。

Release validation used the normal workflow path with the same two-character YuE2 v1.6.1 sheet and bundle. All five H3 segments passed review. The final H.264/AAC file is exactly 60.000 seconds at 864×480 and 24fps, four Japanese subtitle cues were visibly burned, and source-audio correlation was 0.999743 over the unfaded first 58 seconds. Inspected frames kept Akari and Hikari distinct without a visible merge, clone, or identity swap. / 公開前検証では、YuE2 v1.6.1の同じ2人物シートとバンドルを通常経路へ入力し、H3の5区間すべてが検査合格しました。完成H.264/AACは60.000秒、864×480、24fpsで、日本語字幕4区間の焼き込みを実フレームで確認。フェード前58秒の元音源相関は0.999743で、確認フレームではアカリとヒカリの融合・分身・入れ替わりは見られませんでした。

Bundles without visual metadata retain the legacy single-character path. Unit and regression checks cover two-character contracts, six-section Ref2VA instructions, malformed/duplicate character data, and legacy fallback. Exact identity remains model-dependent and the generated video must be visually reviewed. / visual情報のないバンドルは従来の1人物経路を維持します。2人物契約、Ref2VAの6セクション、不正・重複人物情報、旧版フォールバックを単体・回帰検査します。厳密な人物一致はモデル依存のため、生成映像は目視確認が必要です。
